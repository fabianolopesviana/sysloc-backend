## 4. Detalhes de Implementação

### 4.1 Contexto

`montar_pdf_consolidado` (`boletos_abertos.py`) devolve `{total, pdf_bytes, disponiveis, ausentes}`. O endpoint `baixar_consolidado_boletos_abertos` grava **apenas** `pdf_bytes` em `frappe.local.response` e termina — sem `return`, sem header, sem canal para o resto.

`listar_boletos_abertos` existe e é testada (CT-019 atual), mas é **função interna**.

Resultado: a tela não tem como avisar "N boletos ficaram de fora do consolidado" (CA-10) nem exibir a contagem para o fluxo de troca.

**Decisão do usuário**: manter o streaming intacto e acrescentar **endpoint(s) JSON irmão(s)** — não usar headers nem converter o PDF para base64.

### 4.2 Correção

- [x] Publicar a apuração de boletos em aberto como método whitelisted, devolvendo ao menos `{total, identificadores}`.
- [x] Publicar o resumo do consolidado como método whitelisted, devolvendo `{total, disponiveis, ausentes}` — **sem** os bytes do PDF.
- [x] Decidir como sênior se são dois métodos ou um só, e justificar. O consumo previsto é: aviso de troca (contagem) e aviso de ausentes (após/antes do download).
- [x] Exigir System Manager em ambos (RN-11), no mesmo padrão dos demais métodos do módulo.
- [x] Documentar o shape no docstring de cada método.

### 4.3 Guardrails de Execução

**DEVE**:

- Manter `baixar_consolidado_boletos_abertos` **byte-a-byte inalterado**.
- Reusar `listar_boletos_abertos` / `montar_pdf_consolidado` — não duplicar a lógica de apuração nem o filtro RN-02.
- Atentar ao custo: o resumo do consolidado **monta o PDF em memória** para saber quem ficou de fora. Se você expuser um método que faz isso, avalie e **registre** o custo (é o mesmo trabalho do download, sem entregar o arquivo). Se achar que existe forma mais barata de derivar `ausentes` sem montar o PDF, proponha e justifique — mas **não** mude a semântica de `ausentes`.
- Rodar a suíte completa.

**NÃO DEVE**:

- **NÃO** devolver bytes de PDF nos métodos JSON.
- **NÃO** alterar `FILTROS_BOLETO_ABERTO` (RN-02, fonte única).
- **NÃO** tornar nenhum método `allow_guest` — expõe a carteira inteira.
- **NÃO** antecipar T2 (fluxo de decisão em `salvar_configuracao`).
